# Drawing App

This a drawing app built by extending the initial template. The following features have been added:

* ColourPalette enhancemenets:
    - RGB colour picker;
    - choosing colours in fill and stroke mode and switching between them; 
    - opacity value and opacity input for fill and stroke;
* Stroke feature
* MenuBox added with:
    - MenuItem for constructing menu options;
    - SaveCanvas for saving images locally;
    - ClearCanvas for clearing the canvas;
    - ImageUpload for adding local images to the canvas;
    - Undo feature and UndoSnapshots to undo and redo 10 recent actions;
* RectangleTool (basic version);
* helperFunctions - saveUndoSnapshot() to save snapshots when changes to canvas have been made;

All the code was written without assistance.
