# Drawing App

This a drawing app built using JavaScript, P5.js and P5.Sound libraries. The following features have been implemented:

* Pencil and Spray tools;
* Colour palette with:
    - an RGB colour picker;
    - choosing colours in fill and stroke mode and switching between them; 
    - opacity input for fill and stroke colours;
* Stroke slider for drawing tools and borders
* Menu:
    - Save Canvas for saving images locally;
    - Clear Canvas for clearing the canvas;
    - Image Upload for adding local images to the canvas;
    - Undo/Redo feature to undo and redo up to 10 recent actions;
* Shape tool for drawing rectangle, tringle, ellipse and heart shapes;
* Select tool for selecting a part of the canvas and applying:
    - move;
    - resize;
    - copy, cut and paste;
    - delete to the selected area;
    - cancel selection;
* EraserTool with circle and square shape for erasing parts of the canvas;
* tooltips for showing tips on tools and function icons;
